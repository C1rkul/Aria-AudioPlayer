## 🇷🇺 Aria v0.2.0-beta — Русский

Первый публичный релиз локального аудио-плеера **Aria** (Go + Wails + Svelte).

**Что внутри**
- Локальная библиотека: файлы или папка целиком, теги и обложки, поиск. Форматы: mp3, wav, ogg, flac, m4a, aac.
- Воспроизведение: перемотка, громкость, повтор, перемешивание, сохранение паузы при смене трека, восстановление последнего трека.
- Большая страница Now Playing: обложка, визуализатор, адаптивный фон под цвет обложки, панель текста (заготовка).
- Оформление: тёмная/светлая тема, Glassmorphism, 4 анимированных фона с настройками, свой акцентный цвет, неоновая обводка, плавные переходы и заставка.

**Как запустить:** скачайте `audioplayer.exe` и запустите (нужен Microsoft WebView2 — есть в Windows 10/11).

**В разработке:** кроссфейд, поиск текстов через внешний API, внешние источники.

⚠️ Бета-версия: возможны ошибки. Сообщить о проблеме можно в Issues.

## 🇬🇧 Aria v0.2.0-beta — English

First public release of **Aria**, a local audio player (Go + Wails + Svelte).

**What's inside**
- Local library: files or a whole folder, tags and cover art, search. Formats: mp3, wav, ogg, flac, m4a, aac.
- Playback: seek, volume, repeat, shuffle, pause state kept when switching tracks, restore last track.
- Now Playing page: cover art, visualizer, adaptive background that follows the cover color, lyrics panel (stub).
- Look & feel: dark/light theme, Glassmorphism, 4 animated backgrounds with settings, custom accent color, neon outline, smooth transitions and a splash screen.

**How to run:** download `audioplayer.exe` and launch it (Microsoft WebView2 is required — included in Windows 10/11).

**Work in progress:** crossfade, lyrics via an external API, external sources.

⚠️ Beta: bugs are possible. Please report issues in Issues.
